# הרצאה 7 - MapReduce מתקדם

### שאלה 1
מה המטרה העיקרית של Combiner ב־MapReduce?

A. להחליף את ה־Reducer לחלוטין
B. לבצע אגרגציה מקומית כדי לצמצם תעבורת Shuffle
C. לחלק נתונים בין קלאסטרים שונים
D. לשמור תוצאות ל־HDFS

**תשובה נכונה:** B

### שאלה 2
מה עושה Partitioner מותאם אישית?

A. מגדיר את מספר ה־Mappers
B. קובע לאיזה Reducer יישלח כל מפתח
C. משנה את פורמט הקלט לקובץ JSON
D. מבצע נרמול של נתונים

**תשובה נכונה:** B

### שאלה 3
אם יש 3 Reducers ומפתחי הפלט הם A, B, C, D, E עם hash שמחלק לפי A/B->R1, C/D->R2, E->R3, כמה Reducers יקבלו נתונים?

A. 1
B. 2
C. 3
D. 5

**תשובה נכונה:** C

### שאלה 4
מהו Skew ב־MapReduce וכיצד מתמודדים איתו?

A. מצב שבו כל ה־Reducers מקבלים בדיוק אותה כמות עבודה; מטפלים עם Combiner
B. מצב שבו מפתח אחד שולט בנפח הנתונים; מטפלים בעזרת Partitioning מותאם או Salting
C. מצב שבו הקלט לא דחוס; מטפלים עם Compression
D. מצב שבו ה־Mapper נכשל; מטפלים עם Retry בלבד

**תשובה נכונה:** B
