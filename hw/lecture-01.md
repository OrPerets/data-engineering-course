# שאלות תרגול – הרצאה 01: מבוא להנדסת נתונים

### שאלה 1
מהו ההבדל המרכזי בין Data Engineer ל-Data Scientist?

A. Data Engineer מתמקד בהצגת גרפים בלבד
B. Data Engineer אחראי על תשתיות, צינורות נתונים ואמינות נתונים
C. Data Engineer עובד רק עם מודלים סטטיסטיים
D. אין שום הבדל בין התפקידים

**תשובה נכונה:** B

### שאלה 2
איזה מהבאים הוא שלב אופייני בצינור נתונים (Data Pipeline)?

A. איסוף נתונים → עיבוד → אחסון → צריכה
B. צריכה → אחסון → עיבוד → איסוף
C. עיבוד → צריכה → איסוף → אחסון
D. אחסון → איסוף → צריכה → עיבוד

**תשובה נכונה:** A

### שאלה 3
חברה אוספת 2GB נתונים בכל שעה. כמה נתונים תאסוף ביממה (24 שעות)?

A. 12GB
B. 24GB
C. 48GB
D. 96GB

**תשובה נכונה:** C

### שאלה 4
מהי אחת הסיבות העיקריות לשימוש ב-ETL?

A. כדי להקטין את מספר המשתמשים
B. כדי להעביר נתונים ממקורות שונים למבנה אחיד ונקי
C. כדי להימנע מגיבויים
D. כדי להפסיק עיבוד נתונים

**תשובה נכונה:** B

### שאלה 5
אם מערכת צריכה לטפל ב-10,000 אירועים בשנייה, כמה אירועים יעובדו בדקה?

A. 60,000
B. 600,000
C. 6,000,000
D. 600

**תשובה נכונה:** B
